# 🖐 onehand — 한손으로 카페 닉네임 → 룰렛 넣기

오른손을 못 쓰는 동안 **네이버 카페 글 작성자 닉네임을 타이핑 없이** 룰렛에 넣기 위한 도구 모음이에요.

| 파일 | 역할 |
| --- | --- |
| `onehand-cafe-picker.user.js` | 크롬 유저스크립트. 카페 글을 열면 작성자 닉네임이 **자동으로 클립보드에 복사**되고, 버튼 하나로 목록에 모아 둘 수 있음 |
| `roulette-paste.ahk` | (선택) 룰렛 창에서 **마우스 옆버튼 한 번 = 붙여넣기 + Enter** |

---

## 1. 유저스크립트 설치 (필수, 5분)

1. 크롬에 [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) 확장 설치
2. `chrome://extensions` → Tampermonkey **세부정보** → **"사용자 스크립트 허용(Allow User Scripts)"** 켜기
   (최신 크롬은 이걸 켜야 유저스크립트가 돌아가요. 안 보이면 오른쪽 위 **개발자 모드**를 켜세요)
3. Tampermonkey 아이콘 → **새 스크립트 만들기** → 기본 내용을 지우고 `onehand-cafe-picker.user.js` 내용을 붙여넣은 다음 `Ctrl+S`
4. 네이버 카페 글을 열면 오른쪽 아래에 초록색 **"🖐 한손 닉네임 수집기"** 패널이 떠요 (윗부분을 잡고 끌어서 옮길 수 있어요)

## 2. 방송 중에 쓰는 법

### 방법 A — 한 명씩 바로 넣기 (지금 하던 방식 그대로)
1. 카페에서 글을 클릭 → 작성자 닉네임이 **이미 클립보드에 복사돼 있어요**
2. 룰렛의 `항목 추가` 칸 클릭 → **붙여넣기** (`Ctrl+V`, 우클릭 → 붙여넣기, 또는 아래 AHK의 마우스 옆버튼)
3. 다음 글로 이동 → 반복

### 방법 B — 먼저 다 모으고 한 번에 넣기
1. 글을 열 때마다 패널의 **➕ 복사 + 목록에 추가**를 클릭 (또는 키보드 <kbd>`</kbd>, 숫자 1 왼쪽 키)
   - 같은 글이나 같은 닉네임은 자동으로 걸러져요 (설정에서 중복 허용 가능)
   - 잘못 넣었으면 **↩ 마지막 취소**나 목록의 ✕
2. 다 모았으면 **📋 전체 복사** → 룰렛에 붙여넣기
   - 룰렛이 여러 줄 붙여넣기를 지원하면 한 번에 끝나요. 쉼표로 구분해야 하는 룰렛이면 `설정 → 전체 복사 구분자`를 쉼표로 바꾸세요
   - 한 줄씩만 받는 룰렛이면 방법 A를 쓰세요

### 🎯 직접 선택 모드
네이버가 화면 구조를 바꿔서 닉네임이 자동으로 안 잡히거나, **댓글 작성자**를 모아야 할 때:
**🎯 직접 선택**을 켜고 화면의 닉네임을 클릭하면 바로 복사되고 목록에 추가돼요. 다 쓰면 다시 눌러서 끄세요.

### 설정
- **글 열면 작성자 자동 복사** (기본 켜짐)
- **글 열면 목록에 자동 추가** (기본 꺼짐) — 이벤트 글만 차례로 열 거라면 켜 두면 클릭조차 필요 없어요
- **같은 닉네임 중복 허용** (기본 꺼짐) — 글 1개당 1표로 하려면 켜세요

수집 목록은 브라우저에 저장돼서 새로고침하거나 탭을 닫아도 남아 있어요.

## 3. (선택) 마우스 옆버튼으로 붙여넣기 + Enter

왼손이 마우스에 있는 상태에서 `Ctrl+V`와 `Enter`를 누르려고 손을 옮기기 번거롭다면:

1. [AutoHotkey v2](https://www.autohotkey.com/) 설치
2. `roulette-paste.ahk` 더블클릭으로 실행 (작업표시줄 트레이에 H 아이콘이 생겨요)
3. **룰렛 창이 활성화된 상태에서만** 다음처럼 동작해요 (카페 브라우저의 '뒤로 가기'는 그대로예요)
   - 마우스 **앞쪽 옆버튼**: 붙여넣기 + Enter
   - 마우스 **뒤쪽 옆버튼**: 붙여넣기만
   - **F1**: 붙여넣기 + Enter (옆버튼 없는 마우스용)

룰렛 창 제목이 "돌려돌려 돌림판"이 아니면 스크립트 안의 그 글자를 실제 창 제목 일부로 바꾸면 돼요.
룰렛에서 Enter로 항목이 추가되지 않으면 `PasteEnter()` 안의 `{Enter}`를 지우고 쓰면 돼요.

### 이렇게 하면 한 명 넣는 동작은
**카페에서 글 클릭 → 룰렛 입력칸 클릭 → 옆버튼 클릭** — 마우스만으로 3번 클릭이면 끝나요.

## 문제 해결
- **패널이 안 떠요** → 2번 단계("사용자 스크립트 허용")를 확인하고, Tampermonkey 아이콘에서 스크립트가 켜져 있는지 보세요.
- **패널은 뜨는데 닉네임이 안 잡혀요** → 네이버 화면 구조가 바뀐 거예요. 일단 **🎯 직접 선택**으로 쓰고, 스크립트 위쪽 `AUTHOR_SELECTORS`에 새 선택자를 추가하면 고칠 수 있어요.
- **닉네임 대신 댓글 쓴 사람이 잡혀요** → 글 상단(`.ArticleTopBox`) 안에서만 찾도록 돼 있어서 보통은 그렇지 않아요. 생기면 알려 주세요.
