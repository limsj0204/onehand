# 🖐 onehand — 한손으로 카페 닉네임 → 룰렛 넣기

오른손을 못 쓰는 동안 **네이버 카페 글 작성자 닉네임을 타이핑 없이** 룰렛에 넣기 위한 도구 모음이에요.

두 가지 방식 중 하나를 고르면 돼요.

| | 설치 | 방송 중 동작 |
| --- | --- | --- |
| **A. 북마클릿** (`bookmarklet/`) | 즐겨찾기 하나 추가, **확장 설치 없음** | 글 열고 북마크바의 **작성자 복사** 클릭 → 붙여넣기 |
| **B. 유저스크립트** (`onehand-cafe-picker.user.js`) | Tampermonkey 확장 필요 | 글만 열면 **자동 복사** → 붙여넣기 (중복 닉네임 경고 포함) |

어느 쪽이든 룰렛 쪽에서는 `roulette-paste.ahk`(선택)로 **마우스 옆버튼 한 번 = 붙여넣기 + Enter**를 쓸 수 있어요.

---

## A. 북마클릿 (설치 없이)

북마클릿은 주소 대신 짧은 코드가 들어 있는 즐겨찾기예요. 누르면 지금 보고 있는 카페 글에서 작성자를 찾아 복사해요.

### 추가하기
1. `bookmarklet/install.html`을 크롬으로 열기 (파일을 크롬 창에 끌어다 놓으면 돼요)
2. 초록색 **작성자 복사** 버튼을 마우스로 잡고 **북마크바**(주소창 바로 아래)로 끌어다 놓기
   - 북마크바가 안 보이면 `Ctrl+Shift+B`
   - 끌어다 놓기가 안 되면: 북마크바 우클릭 → **페이지 추가** → URL 칸에 `bookmarklet/bookmarklet.txt` 내용을 통째로 붙여넣기

### 쓰기
1. 카페 글 열기
2. 북마크바의 **작성자 복사** 클릭 → 화면 위에 초록색 "📋 닉네임 복사됨"이 떠요
3. 룰렛 `항목 추가` 칸에 붙여넣기

빨간색 "작성자를 못 찾았어요"가 뜨면 글이 다 열리기 전에 눌렀거나, 네이버 화면 구조가 바뀐 거예요.

> 코드를 고치려면 `bookmarklet/copy-author.js`를 수정한 뒤 `node bookmarklet/build.js`로 `bookmarklet.txt`/`install.html`을 다시 만들고, 즐겨찾기도 다시 추가하세요.

# B. 유저스크립트 (Tampermonkey)

## 1. 유저스크립트 설치 (필수, 5분)

1. 크롬에 [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) 확장 설치
2. `chrome://extensions` → Tampermonkey **세부정보** → **"사용자 스크립트 허용(Allow User Scripts)"** 켜기
   (최신 크롬은 이걸 켜야 유저스크립트가 돌아가요. 안 보이면 오른쪽 위 **개발자 모드**를 켜세요)
3. Tampermonkey 아이콘 → **새 스크립트 만들기** → 기본 내용을 지우고 `onehand-cafe-picker.user.js` 내용을 붙여넣은 다음 `Ctrl+S`
4. 네이버 카페 글을 열면 오른쪽 아래에 초록색 **"🖐 작성자 자동 복사"** 패널이 떠요 (윗부분을 잡고 끌어서 옮길 수 있고, — 버튼으로 접을 수 있어요)

## 2. 방송 중에 쓰는 법

1. 카페에서 글을 클릭 → 작성자 닉네임이 **이미 복사돼 있어요** (패널에 "✅ 복사됨"과 닉네임이 크게 표시돼요)
2. 룰렛의 `항목 추가` 칸 클릭 → **붙여넣기** (`Ctrl+V`, 우클릭 → 붙여넣기, 또는 아래 AHK의 마우스 옆버튼)
3. 다음 글로 이동 → 반복

### 패널 기능
- **⚠ 중복 닉네임 경고**: 앞에서 연 다른 글에도 같은 작성자가 있었으면 주황색으로 알려 줘요. 한 사람이 글을 여러 개 올렸을 때 넣을지 말지 판단하기 좋아요. 새 이벤트를 시작할 때는 **중복 기록 초기화**를 눌러 주세요.
- **📋 다시 복사** (또는 <kbd>`</kbd> 키, 숫자 1 왼쪽): 다른 걸 복사해서 클립보드가 바뀌었을 때 현재 글 작성자를 다시 복사해요.
- **🎯 직접 선택**: 네이버가 화면 구조를 바꿔서 닉네임이 자동으로 안 잡히거나, 댓글 작성자를 넣어야 할 때 쓰세요. 켜고 화면의 닉네임을 클릭하면 그 글자가 복사되고, 한 번 집으면 자동으로 꺼져요.

## 3. (선택) 마우스 옆버튼으로 붙여넣기 + Enter

왼손이 마우스에 있는 상태에서 `Ctrl+V`와 `Enter`를 누르려고 손을 옮기기 번거롭다면:

1. [AutoHotkey v2](https://www.autohotkey.com/) 설치
2. `roulette-paste.ahk` 더블클릭으로 실행 (작업표시줄 트레이에 H 아이콘이 생겨요)
3. **룰렛 창이 활성화된 상태에서만** 다음처럼 동작해요 (카페 브라우저의 '뒤로 가기'는 그대로예요)
   - 마우스 **앞쪽 옆버튼**: 붙여넣기 + Enter
   - 마우스 **뒤쪽 옆버튼**: 붙여넣기만
   - **F1**: 붙여넣기 + Enter (옆버튼 없는 마우스용)

룰렛 창 제목이 "돌려돌려 돌림판"이 아니면 스크립트 안의 그 글자를 실제 창 제목 일부로 바꾸면 돼요.
룰렛에서 Enter로 항목이 추가되지 않으면 `PasteEnter()` 안의 `{Enter}`를 지우고 쓰면 돼요.

### 이렇게 하면 한 명 넣는 동작은
**카페에서 글 클릭 → 룰렛 입력칸 클릭 → 옆버튼 클릭** — 마우스만으로 3번 클릭이면 끝나요.

## 문제 해결
- **패널이 안 떠요** → 2번 단계("사용자 스크립트 허용")를 확인하고, Tampermonkey 아이콘에서 스크립트가 켜져 있는지 보세요.
- **패널은 뜨는데 닉네임이 안 잡혀요** → 네이버 화면 구조가 바뀐 거예요. 일단 **🎯 직접 선택**으로 쓰고, 스크립트 위쪽 `AUTHOR_SELECTORS`에 새 선택자를 추가하면 고칠 수 있어요.
- **닉네임 대신 댓글 쓴 사람이 잡혀요** → 글 상단(`.ArticleTopBox`) 안에서만 찾도록 돼 있어서 보통은 그렇지 않아요. 생기면 알려 주세요.
